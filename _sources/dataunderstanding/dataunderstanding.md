# Data Understanding

## Macam-Macam Data

1. Data terstruktur (structured)  
2. Data tidak terstruktur (unstructured)  
3. Data bahasa alami (Natural Language)  
4. Data yang dibangkitkan oleh mesin (Machine-Generated)  
5. Data audio, video, dan citra  
6. Data streaming  
7. Data berbasis graph (graph-based)

---

## Data Terstruktur

Data terstruktur adalah data yang bergantung pada model data dan dinyatakan dalam bentuk tabel dengan atribut (kolom) dan baris. Data terstruktur mudah disimpan dalam database dalam bentuk tabel atau file Excel (Ms Office) serta SQL (Structured Query Language), sehingga mudah dilakukan query terhadap data tersebut. Namun pada kenyataannya, banyak data yang berbentuk tidak terstruktur karena data dihasilkan oleh manusia dan mesin.

---

### Macam-Macam Atribut

1. Nominal → kategori tanpa urutan  
2. Biner → dua nilai (0/1), bisa simetris atau asimetris  
3. Ordinal → ada urutan, tanpa jarak pasti  
4. Numerik:  
   - Interval → tanpa nol mutlak (contoh: suhu)  
   - Rasio → ada nol mutlak (contoh: berat, tinggi)

---

## Data Tidak Terstruktur

Data tidak terstruktur adalah data yang tidak mudah dimasukkan ke dalam model data karena isi atau kontennya sangat spesifik dan bervariasi. Salah satu contoh data tidak terstruktur adalah email. Meskipun email memiliki elemen terstruktur seperti pengirim, judul, dan isi teks, terdapat banyak variasi isi seperti dialek bahasa yang digunakan dan lain sebagainya. Email juga merupakan salah satu contoh data bahasa alami.

---

### Bahasa Alami

Dalam neuropsikologi, linguistik, dan filsafat bahasa, bahasa alami atau bahasa biasa adalah bahasa yang berevolusi secara alami pada manusia melalui penggunaan dan pengulangan tanpa perencanaan. Bahasa alami berbeda dengan bahasa yang dibangun untuk pemrograman komputer atau logika formal. Bahasa alami dikenal sebagai bahasa manusia, misalnya Bahasa Indonesia, Bahasa Inggris, dan lain-lain.

---

## Data yang Dibangkitkan oleh Mesin

Data yang dibangkitkan oleh mesin adalah data yang dihasilkan secara otomatis tanpa intervensi manusia. Data ini terus-menerus dihasilkan selama suatu proses berjalan. Contohnya adalah data weblog dari server yang dihasilkan dari transaksi pengguna dengan sistem web.

---

## Data Jaringan atau Data Berbasis Graph

Data graph adalah data yang direpresentasikan dalam bentuk graph yang dalam matematika mengacu pada teori graph. Data ini menunjukkan keterhubungan antar objek menggunakan struktur node, edge, dan karakteristik relasi antar objek tersebut.

---

## Data Audio, Video, dan Citra

Dengan perkembangan teknologi multimedia yang sangat pesat, data audio, video, dan citra dihasilkan dalam jumlah besar dari berbagai transaksi bisnis. Besarnya data yang dihasilkan membutuhkan proses pengolahan khusus agar dapat dimanfaatkan, terutama dalam analisis data sains. Pemanfaatan data multimedia antara lain pengenalan objek, pengenalan suara, segmentasi citra satelit, dan berbagai analisis lainnya.

---

## Data Streaming

Data streaming adalah data yang dihasilkan secara terus-menerus oleh ribuan sumber data yang biasanya mengirimkan catatan data secara bersamaan dalam ukuran kecil (urutan kilobyte).

---

## Distribusi Data

Karakteristik utama dari data adalah distribusi probabilitasnya. Distribusi data yang paling dikenal adalah distribusi normal atau Gaussian. Distribusi ini banyak ditemukan pada sistem fisik di mana data dibangkitkan secara acak.
