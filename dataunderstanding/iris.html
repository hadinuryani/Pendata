Distence Iris#

Menghitung jarak data numerik menggunakan dataset Iris. Dataset Iris hanya memiliki atribut numerik sehingga cocok untuk perhitungan jarak Euclidean dan Manhattan Fitur numerik:

  • sepal length

  • sepal width

  • petal length

  • petal width

import pandas as pd
import numpy as np
from sklearn.datasets import load_iris

iris = load_iris()
df_iris = pd.DataFrame(iris.data, columns=iris.feature_names)
df_iris.head()
sepal length (cm) sepal width (cm) petal length (cm) petal width (cm)
0 5.1 3.5 1.4 0.2
1 4.9 3.0 1.4 0.2
2 4.7 3.2 1.3 0.2
3 4.6 3.1 1.5 0.2
4 5.0 3.6 1.4 0.2

cek tipe data numeric#

df_numeric = df_iris.select_dtypes(include=[np.number])
print(df_numeric.dtypes)

sepal length (cm)    float64
sepal width (cm)     float64
petal length (cm)    float64
petal width (cm)     float64
dtype: object

Ambil dua sampel#

point1 = df_numeric.iloc[0]
point2 = df_numeric.iloc[1]

Euclidean Distance#

euclidean_distance = np.sqrt(np.sum((point1 - point2)**2))
print("Jarak Euclidean:", euclidean_distance)

Jarak Euclidean: 0.5385164807134502

Manhattan Distance#

manhattan_distance = np.sum(abs(point1 - point2))
print("Jarak Manhattan:", manhattan_distance)

Jarak Manhattan: 0.6999999999999993
